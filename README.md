# 📱 CRUD - Catálogo de Celulares

## 📖 Sobre o projeto

Este projeto é um sistema de catálogo de celulares desenvolvido em Python. Ele permite realizar operações de CRUD (Create, Read, Update e Delete) para gerenciar um catálogo de produtos.

## 🚀 Funcionalidades

- ✅ Cadastrar celulares
- ✅ Listar celulares cadastrados
- ✅ Atualizar informações de um celular
- ✅ Excluir celulares
- ✅ Adicionar quantidade ao estoque
- ✅ Remover quantidade do estoque
- ✅ Buscar celulares por marca
- ✅ Menu interativo no terminal

## 🛠️ Tecnologias utilizadas

- Python 3

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/AdrielGomes062/Crud-Celulares-Python.git
```

2. Entre na pasta do projeto:

```bash
cd Crud-Celulares-Python
```

3. Execute o programa:

```bash
python Projeto02.py
```
